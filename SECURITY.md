# Reporte responsable de vulnerabilidades

## Alcance

Este repositorio contiene el código de Voz y Palabra. Los reportes deben limitarse a vulnerabilidades reproducibles que afecten al código, la configuración de despliegue o las políticas de acceso incluidas aquí.

## Cómo reportar

Usa la función de reporte privado de vulnerabilidades de GitHub (pestaña **Security** → **Report a vulnerability**) para evitar publicar credenciales, datos personales o una prueba de concepto sensible.

Si esa función no está disponible, abre un issue sin incluir secretos ni datos personales y solicita un canal privado al mantenedor. No publiques tokens, contraseñas, NIP, boletas, correos de usuarios ni datos de producción.

Incluye una descripción breve, pasos para reproducir, impacto estimado y una forma segura de contactarte. No ejecutes pruebas contra producción sin autorización explícita.

## Respuesta

Confirmaremos la recepción cuando tengamos acceso al reporte, validaremos el alcance y coordinaremos la corrección o mitigación antes de publicar detalles técnicos.
